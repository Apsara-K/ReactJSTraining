HTML

HTML is the standard markup language used to create web pages. It provides the basic structure of a webpage using elements such as headings, paragraphs, images, tables, and forms.

CSS

CSS is used to style web pages by changing colors, fonts, spacing, layouts, and animations. It helps create attractive and responsive websites that work on different screen sizes.

JavaScript

JavaScript adds interactivity to websites. It can handle events, validate forms, update webpage content dynamically, and create interactive applications for users.
